# `labels/` — hand-labelled ground truth

Empty by design, and tracked so a clone gets the directory.

Finding-quality scoring (precision, recall, actionability) needs a human
adjudication of what a *correct* finding would have been on each case. That is
`agent-ix/quoin#197`'s dictionary and population — a **sibling** programme, not
this EPIC's — so the labels land when a runner consumes them, not before.

Seeding this with guesses would be worse than leaving it empty: a label nobody
adjudicated is an answer key that scores agreement with itself.
